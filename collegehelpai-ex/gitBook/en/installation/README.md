# 📦 Installing AI College Help

## Overview

AI College Help is compatible with the most popular browsers. This section guides you through the complete installation process for each supported browser.

### 🌐 Supported Browsers

| Browser | Minimum Version | Status | Installation Guide |
|---------|-----------------|--------|-------------------|
| **Google Chrome** | Version 88+ | ✅ Fully supported | [Chrome Guide](chrome.md) |
| **Microsoft Edge** | Version 88+ | ✅ Fully supported | [Edge Guide](edge.md) |
| **Mozilla Firefox** | Version 78+ | 🔄 Coming Soon | Firefox support in development |

### ⚡ Quick Installation

**Estimated time:** 2-3 minutes per browser

1. **Choose your browser** from the table above
2. **Follow the corresponding guide** step by step
3. **Verify the installation** with our [verification guide](verification.md)

### 📋 Prerequisites

Before installation, make sure that:

- ✅ Your browser is up to date
- ✅ You have a stable internet connection
- ✅ You can install extensions (no administrator restrictions)

### 🔐 Required Permissions

The extension requests the following permissions to function:

| Permission | Usage | Required |
|------------|-------|----------|
| **Active Tab** | Analyze content of the active page | ✅ Yes |
| **Storage** | Save your preferences | ✅ Yes |
| **Screenshots** | Capture screen areas | ✅ Yes |
| **Context Menus** | Custom right-click menu | ✅ Yes |

> **🛡️ Security:** All data is encrypted and stored securely according to our [privacy policy](https://collegehelpai.com/privacy-policy/).

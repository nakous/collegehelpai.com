# 🟢 Installing on Google Chrome

## Step-by-Step Installation Guide

### Method 1: Installation from Chrome Web Store (Recommended)

#### Step 1: Open Chrome Web Store

1. **Open Google Chrome** on your computer
2. **Navigate to** the official extension page: [AI College Help on Chrome Web Store](https://chromewebstore.google.com/detail/ai-college-help-for-homew/hkpnmedofadjhlllcppmpadkadhcnpbe)
3. **Or search manually** by going to [chrome.google.com/webstore](https://chrome.google.com/webstore)

---

**📸 Screenshot placeholder:** *Chrome Web Store homepage*

---

#### Step 2: Find AI College Help

**If using the direct link:**
- The extension page opens immediately

**If searching manually:**
1. **Click on the search bar** at the top of the page
2. **Type** "AI College Help" or "College Help AI"
3. **Press Enter** or click the search icon
4. **Look for** "AI College Help - for homework and study"

---

**📸 Screenshot placeholder:** *Search results for AI College Help*

---

#### Step 3: Install the Extension

1. **Locate** "AI College Help - for homework and study" in the results
2. **Click on the extension** to open its page
3. **Verify** it's the correct extension:
   - ✅ Official developer: College Help AI Team
   - ✅ Good ratings and reviews
   - ✅ Recent updates
   - ✅ Correct icon and description
4. **Click "Add to Chrome"**

---

**📸 Screenshot placeholder:** *Extension page with "Add to Chrome" button*

---

#### Step 4: Confirm Installation

1. **A popup appears** with the list of permissions
2. **Carefully read** the requested permissions:
   - Read and change data on websites
   - Manage downloads
   - Store local data
3. **Click "Add extension"** to confirm

---

**📸 Screenshot placeholder:** *Permission confirmation popup*

---

#### Step 5: Installation Verification

1. **The AI College Help icon** appears in the Chrome toolbar
2. **A confirmation message** is displayed
3. **The extension is ready** to be used

### Post-Installation Configuration

#### Pin the Extension

For easy access, pin the extension:

1. **Click on the puzzle icon** 🧩 in the toolbar
2. **Find "AI College Help"** in the list
3. **Click the pin icon** 📌 to pin it

---

**📸 Screenshot placeholder:** *Extensions menu with pin option*

---

#### Configure Shortcuts (Optional)

1. **Go to** `chrome://extensions/shortcuts`
2. **Find "AI College Help"**
3. **Configure your preferred shortcuts**:
   - Ask College Help: `Ctrl+Shift+A`
   - Take Screenshot: `Ctrl+Shift+S`

---

**📸 Screenshot placeholder:** *Keyboard shortcuts configuration page*

---

### Method 2: Manual Installation (Developers)

#### If you have the .crx file or source folder:

1. **Open Chrome** and type `chrome://extensions/` in the address bar
2. **Enable "Developer mode"** (toggle in top right)
3. **Click "Load unpacked extension"**
4. **Select** the folder containing the extension
5. **The extension loads** automatically

---

### 🔧 Chrome Troubleshooting

**Extension doesn't appear?**
- Verify Chrome is up to date (version 88+)
- Restart Chrome completely
- Check in `chrome://extensions/` that the extension is enabled

**Permissions denied?**
- The extension cannot function without permissions
- Uninstall and reinstall, accepting all permissions

**Other issues?**
- Check our [troubleshooting guide](../troubleshooting/installation.md)
- Contact our [support](https://collegehelpai.com/contact-us/)

### 💡 Chrome Tips

- **Sync:** Your Chrome extensions sync across all your connected devices
- **Updates:** Chrome automatically updates extensions
- **Management:** You can temporarily disable the extension without uninstalling it

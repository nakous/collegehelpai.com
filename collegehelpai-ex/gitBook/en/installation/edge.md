# 🔵 Installing on Microsoft Edge

## Step-by-Step Installation Guide

### Method 1: Installation from Microsoft Edge Add-ons (Recommended)

#### Step 1: Open Microsoft Edge Add-ons

1. **Open Microsoft Edge** on your computer
2. **Navigate to** the official extension page: [AI College Help on Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/ai-college-help-for-hom/ldfjgaenfdeocmcjjhdhhfoeaphcbeln?hl=en-US&gl=US)
3. **Or search manually** by going to [microsoftedge.microsoft.com/addons](https://microsoftedge.microsoft.com/addons)

---

**📸 Screenshot placeholder:** *Microsoft Edge Add-ons homepage*

---

#### Step 2: Find AI College Help

**If using the direct link:**
- The extension page opens immediately

**If searching manually:**
1. **Click on the search bar** at the top of the page
2. **Type** "AI College Help" or "College Help AI"
3. **Press Enter** or click the search icon
4. **Look for** "AI College Help - for homework and study"

---

**📸 Screenshot placeholder:** *Search results for AI College Help on Edge*

---

#### Step 3: Install the Extension

1. **Locate** "AI College Help - for homework and study" in the results
2. **Click on the extension** to open its page
3. **Verify** it's the correct extension:
   - ✅ Official developer: College Help AI Team
   - ✅ Good ratings and reviews
   - ✅ Recent updates
   - ✅ Correct description and features
4. **Click "Get"** or "Add to Edge"

---

**📸 Screenshot placeholder:** *Extension page with "Get" button*

---

#### Step 4: Confirm Installation

1. **A popup appears** with the list of permissions
2. **Carefully read** the requested permissions:
   - Read and change data on websites
   - Access tabs and browsing activity
   - Store local data
3. **Click "Add extension"** to confirm

---

**📸 Screenshot placeholder:** *Permission confirmation popup in Edge*

---

#### Step 5: Installation Verification

1. **The AI College Help icon** appears in the Edge toolbar
2. **A confirmation message** is displayed
3. **The extension is ready** to be used

---

**📸 Screenshot placeholder:** *Extension icon in Edge toolbar*

---

### Method 2: Installation from Chrome Web Store

Microsoft Edge, being based on Chromium, can use Chrome extensions:

#### Step 1: Enable Chrome Extensions

1. **Open Edge** and type `edge://extensions/` in the address bar
2. **Enable** "Allow extensions from other stores"
3. **Click "Allow"** in the confirmation popup

---

**📸 Screenshot placeholder:** *"Allow extensions from other stores" option*

---

#### Step 2: Install from Chrome Web Store

1. **Visit** the [Chrome Web Store](https://chrome.google.com/webstore)
2. **Search** for "AI College Help"
3. **Follow** the same steps as for Chrome
4. **Edge will automatically** install the extension

---

**📸 Screenshot placeholder:** *Installing from Chrome Web Store in Edge*

---

### Post-Installation Configuration

#### Pin the Extension

For easy access, pin the extension:

1. **Click on the puzzle icon** 🧩 or "Extensions" in the toolbar
2. **Find "AI College Help"** in the list
3. **Click the eye icon** 👁️ to show it in the toolbar

---

**📸 Screenshot placeholder:** *Extensions menu with show option*

---

#### Configure Shortcuts (Optional)

1. **Go to** `edge://extensions/shortcuts`
2. **Find "AI College Help"**
3. **Configure your preferred shortcuts**:
   - Ask College Help: `Ctrl+Shift+A`
   - Take Screenshot: `Ctrl+Shift+S`

---

**📸 Screenshot placeholder:** *Edge keyboard shortcuts configuration page*

---

### Method 3: Manual Installation (Developers)

#### If you have the source files:

1. **Open Edge** and type `edge://extensions/` in the address bar
2. **Enable "Developer mode"** (toggle at bottom left)
3. **Click "Load unpacked"**
4. **Select** the folder containing the extension
5. **The extension loads** automatically

---

### 🔧 Edge Troubleshooting

**Extension doesn't appear?**
- Verify Edge is up to date (version 88+)
- Restart Edge completely
- Check in `edge://extensions/` that the extension is enabled

**Issues with Chrome extensions?**
- Make sure you've allowed extensions from other stores
- Some features might work slightly differently

**Extensions not syncing?**
- Edge syncs extensions with your Microsoft account
- Check your sync settings

**Other issues?**
- Check our [troubleshooting guide](../troubleshooting/installation.md)
- Contact our [support](https://collegehelpai.com/contact-us/)

### 💡 Edge Tips

- **Microsoft Sync:** Your extensions sync with your Microsoft account
- **Performance:** Edge automatically optimizes extension performance
- **Compatibility:** Most Chrome extensions work perfectly on Edge

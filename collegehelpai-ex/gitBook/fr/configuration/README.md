# ⚙️ Configuration et Paramètres

## Personnalisez Votre Expérience d'Apprentissage

La section Configuration vous permet d'adapter College Help AI à vos besoins spécifiques. Que vous souhaitiez ajuster l'apparence, les raccourcis, la langue ou la gestion du compte, tout est centralisé ici.

### 🎯 Objectifs de la Configuration

- Optimiser votre productivité
- Adapter l'interface à vos préférences
- Activer la discrétion (mode camouflage)
- Gérer votre compte et abonnement
- Contrôler la langue des réponses

### 🧩 Catégories de Paramètres

| Catégorie | Description | Fichier ou Section |
|-----------|-------------|--------------------|
| Paramètres Généraux | Options de base et interface | `parametres-generaux.md` |
| Langues | Choix des langues d'affichage et de réponse | `langues.md` |
| Mode Camouflage | Activation et réglages de la discrétion | `mode-camouflage.md` |
| Raccourcis | Personnalisation des touches rapides | `raccourcis-personnalises.md` |
| Compte & Abonnement | Gestion du profil et des plans | `compte-abonnement.md` |

### 🚀 Accéder aux Paramètres

1. **Ouvrez le popup** College Help AI
2. **Cliquez sur l'icône paramètres** ⚙️ dans l'en-tête
3. **Un panneau latéral** ou un popup s'ouvre avec les catégories

---

**📸 Espace réservé pour capture d'écran :** *Accès au panneau des paramètres depuis le popup principal*

---

### 💡 Conseils Utiles

- Les paramètres sont sauvegardés automatiquement
- La plupart des options sont synchronisées entre navigateurs
- Les raccourcis peuvent être réinitialisés à tout moment
- La langue des réponses peut différer de la langue d'interface

### 🔐 Sécurité des Paramètres

Tous vos paramètres sont :
- Stockés localement via l'API `chrome.storage`
- Chiffrés pour les données sensibles
- Synchronisés si vous êtes connecté

### 🛠️ Paramètres Avancés (Prochaines Versions)

Fonctionnalités prévues :
- Profils d'utilisateur multi-langues
- Exportation/importation des paramètres
- Mode focus pour sessions d'étude

### 📦 Fichier Central des Paramètres

Un fichier dédié regroupe les constantes et préférences (ex : `storage-safety.js`) pour :
- La persistance sécurisée
- La modularité du code
- Les mises à jour simplifiées

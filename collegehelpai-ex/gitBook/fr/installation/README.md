# 📦 Installation de College Help AI

## Vue d'Ensemble

College Help AI est compatible avec les navigateurs les plus populaires. Cette section vous guide à travers le processus d'installation complet pour chaque navigateur supporté.

### 🌐 Navigateurs Supportés

| Navigateur | Version Minimale | Statut | Guide |
|------------|------------------|---------|-------|
| **Google Chrome** | Version 88+ | ✅ Pleinement supporté | [Guide Chrome](chrome.md) |
| **Microsoft Edge** | Version 88+ | ✅ Pleinement supporté | [Guide Edge](edge.md) |
| **Mozilla Firefox** | Version 78+ | ✅ Pleinement supporté | [Guide Firefox](firefox.md) |

### ⚡ Installation Rapide

**Temps estimé :** 2-3 minutes par navigateur

1. **Choisissez votre navigateur** dans le tableau ci-dessus
2. **Suivez le guide** correspondant étape par étape
3. **Vérifiez l'installation** avec notre [guide de vérification](verification.md)

### 📋 Prérequis

Avant l'installation, assurez-vous que :

- ✅ Votre navigateur est à jour
- ✅ Vous avez une connexion Internet stable
- ✅ Vous pouvez installer des extensions (pas de restrictions administrateur)

### 🔐 Permissions Requises

L'extension demande les permissions suivantes pour fonctionner :

| Permission | Utilisation | Obligatoire |
|------------|-------------|-------------|
| **Active Tab** | Analyser le contenu de la page active | ✅ Oui |
| **Storage** | Sauvegarder vos préférences | ✅ Oui |
| **Screenshots** | Capturer des zones d'écran | ✅ Oui |
| **Context Menus** | Menu clic-droit personnalisé | ✅ Oui |

> **🛡️ Sécurité :** Toutes les données sont chiffrées et stockées de manière sécurisée selon notre [politique de confidentialité](https://collegehelpai.com/privacy).

---

**📸 Espace réservé pour capture d'écran :** *Interface de sélection du navigateur*

---

### 🚀 Étapes Suivantes

Une fois l'installation terminée :

1. **[Créez votre compte](../premiers-pas/creation-compte.md)** pour accéder à toutes les fonctionnalités
2. **[Découvrez l'interface](../premiers-pas/interface.md)** avec notre visite guidée
3. **[Configurez vos préférences](../configuration/parametres-generaux.md)** selon vos besoins

### 💡 Conseils d'Installation

- **Installation Multiple :** Vous pouvez installer College Help AI sur plusieurs navigateurs avec le même compte
- **Synchronisation :** Vos paramètres se synchronisent automatiquement entre les appareils
- **Mises à jour :** L'extension se met à jour automatiquement en arrière-plan

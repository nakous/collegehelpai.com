# 🟢 Installation sur Google Chrome

## Guide d'Installation Étape par Étape

### Méthode 1 : Installation depuis le Chrome Web Store (Recommandée)

#### Étape 1 : Ouvrir le Chrome Web Store

1. **Ouvrez Google Chrome** sur votre ordinateur
2. **Naviguez vers** le Chrome Web Store : `chrome://extensions/` ou [chrome.google.com/webstore](https://chrome.google.com/webstore)

---

**📸 Espace réservé pour capture d'écran :** *Page d'accueil du Chrome Web Store*

---

#### Étape 2 : Rechercher College Help AI

1. **Cliquez sur la barre de recherche** en haut de la page
2. **Tapez** "College Help AI" ou "AI College Help"
3. **Appuyez sur Entrée** ou cliquez sur l'icône de recherche

---

**📸 Espace réservé pour capture d'écran :** *Résultats de recherche pour College Help AI*

---

#### Étape 3 : Installer l'Extension

1. **Localisez** "AI College Help - for homework and study" dans les résultats
2. **Cliquez sur l'extension** pour ouvrir sa page
3. **Vérifiez** que c'est la bonne extension (développeur officiel, bonnes évaluations)
4. **Cliquez sur "Ajouter à Chrome"**

---

**📸 Espace réservé pour capture d'écran :** *Page de l'extension avec bouton "Ajouter à Chrome"*

---

#### Étape 4 : Confirmer l'Installation

1. **Une popup apparaît** avec la liste des permissions
2. **Lisez attentivement** les permissions demandées :
   - Lire et modifier les données des sites web
   - Gérer les téléchargements
   - Stocker des données localement
3. **Cliquez sur "Ajouter l'extension"** pour confirmer

---

**📸 Espace réservé pour capture d'écran :** *Popup de confirmation des permissions*

---

#### Étape 5 : Vérification de l'Installation

1. **L'icône College Help AI** apparaît dans la barre d'outils Chrome
2. **Un message de confirmation** s'affiche
3. **L'extension est prête** à être utilisée

---

**📸 Espace réservé pour capture d'écran :** *Icône de l'extension dans la barre d'outils*

---

### Méthode 2 : Installation Manuelle (Développeurs)

#### Si vous avez le fichier .crx ou le dossier source :

1. **Ouvrez Chrome** et tapez `chrome://extensions/` dans la barre d'adresse
2. **Activez le "Mode développeur"** (bouton en haut à droite)
3. **Cliquez sur "Charger l'extension non empaquetée"**
4. **Sélectionnez** le dossier contenant l'extension
5. **L'extension se charge** automatiquement

---

**📸 Espace réservé pour capture d'écran :** *Page chrome://extensions avec mode développeur activé*

---

### Configuration Post-Installation

#### Épingler l'Extension

Pour un accès facile, épinglez l'extension :

1. **Cliquez sur l'icône puzzle** 🧩 dans la barre d'outils
2. **Trouvez "College Help AI"** dans la liste
3. **Cliquez sur l'icône épingle** 📌 pour l'épingler

---

**📸 Espace réservé pour capture d'écran :** *Menu des extensions avec option d'épinglage*

---

#### Configurer les Raccourcis (Optionnel)

1. **Allez dans** `chrome://extensions/shortcuts`
2. **Trouvez "College Help AI"**
3. **Configurez vos raccourcis préférés** :
   - Demander à College Help : `Ctrl+Shift+A`
   - Prendre une capture : `Ctrl+Shift+S`

---

**📸 Espace réservé pour capture d'écran :** *Page de configuration des raccourcis*

### 🔧 Dépannage Chrome

**L'extension n'apparaît pas ?**
- Vérifiez que Chrome est à jour (version 88+)
- Redémarrez Chrome complètement
- Vérifiez dans `chrome://extensions/` que l'extension est activée

**Permissions refusées ?**
- L'extension ne peut pas fonctionner sans les permissions
- Désinstallez et réinstallez en acceptant toutes les permissions

**Autres problèmes ?**
- Consultez notre [guide de dépannage](../depannage/installation.md)
- Contactez notre [support](../ressources/contact.md)

### 💡 Conseils Chrome

- **Synchronisation** : Vos extensions Chrome se synchronisent sur tous vos appareils connectés
- **Mises à jour** : Chrome met automatiquement à jour les extensions
- **Gestion** : Vous pouvez désactiver temporairement l'extension sans la désinstaller

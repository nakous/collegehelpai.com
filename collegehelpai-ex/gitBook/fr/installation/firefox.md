# 🦊 Installation sur Mozilla Firefox

## Guide d'Installation Étape par Étape

### Méthode 1 : Installation depuis Firefox Add-ons (Recommandée)

#### Étape 1 : Ouvrir Firefox Add-ons

1. **Ouvrez Mozilla Firefox** sur votre ordinateur
2. **Naviguez vers** Firefox Add-ons : `about:addons` ou [addons.mozilla.org](https://addons.mozilla.org)
3. **Ou utilisez** le menu : ☰ → Modules complémentaires et thèmes

---

**📸 Espace réservé pour capture d'écran :** *Page d'accueil de Firefox Add-ons*

---

#### Étape 2 : Rechercher College Help AI

1. **Cliquez sur la barre de recherche** "Rechercher des modules complémentaires"
2. **Tapez** "College Help AI" ou "AI College Help"
3. **Appuyez sur Entrée** ou cliquez sur l'icône de recherche

---

**📸 Espace réservé pour capture d'écran :** *Résultats de recherche pour College Help AI*

---

#### Étape 3 : Installer l'Extension

1. **Localisez** "AI College Help - for homework and study" dans les résultats
2. **Cliquez sur l'extension** pour ouvrir sa page
3. **Vérifiez** que c'est la bonne extension :
   - Développeur officiel : College Help AI Team
   - Bonnes évaluations et commentaires
   - Mise à jour récente
4. **Cliquez sur "Ajouter à Firefox"**

---

**📸 Espace réservé pour capture d'écran :** *Page de l'extension avec bouton "Ajouter à Firefox"*

---

#### Étape 4 : Confirmer l'Installation

1. **Une popup apparaît** avec les détails de l'extension
2. **Lisez attentivement** les permissions demandées :
   - Accéder aux données de tous les sites web
   - Accéder aux onglets du navigateur
   - Stocker un volume illimité de données côté client
3. **Cliquez sur "Ajouter"** pour confirmer l'installation

---

**📸 Espace réservé pour capture d'écran :** *Popup de confirmation des permissions Firefox*

---

#### Étape 5 : Vérification de l'Installation

1. **L'icône College Help AI** apparaît dans la barre d'outils Firefox
2. **Une notification** confirme l'installation réussie
3. **L'extension est active** et prête à être utilisée

---

**📸 Espace réservé pour capture d'écran :** *Icône de l'extension dans la barre d'outils Firefox*

### Configuration Post-Installation

#### Épingler l'Extension

Pour un accès facile, épinglez l'extension :

1. **Cliquez droit** sur l'icône de l'extension dans la barre d'outils
2. **Sélectionnez** "Épingler à la barre d'outils"
3. **L'icône reste visible** de manière permanente

---

**📸 Espace réservé pour capture d'écran :** *Menu contextuel avec option "Épingler à la barre d'outils"*

---

#### Configurer les Raccourcis

Firefox permet de personnaliser les raccourcis :

1. **Tapez** `about:addons` dans la barre d'adresse
2. **Cliquez** sur l'icône ⚙️ à côté de College Help AI
3. **Sélectionnez** "Gérer"
4. **Allez à l'onglet** "Raccourcis clavier"
5. **Configurez** vos raccourcis préférés

---

**📸 Espace réservé pour capture d'écran :** *Page de gestion des raccourcis dans Firefox*

### Méthode 2 : Installation Manuelle (Développeurs)

#### Installation depuis un fichier XPI

Si vous avez le fichier `.xpi` :

1. **Ouvrez Firefox** et tapez `about:addons`
2. **Cliquez** sur l'icône ⚙️ en haut de la page
3. **Sélectionnez** "Installer un module depuis un fichier"
4. **Choisissez** le fichier `.xpi` de College Help AI
5. **Confirmez** l'installation

---

**📸 Espace réservé pour capture d'écran :** *Option "Installer un module depuis un fichier"*

---

#### Installation en Mode Développeur

Pour le développement ou les tests :

1. **Tapez** `about:debugging` dans la barre d'adresse
2. **Cliquez** sur "Ce Firefox" dans le menu de gauche
3. **Cliquez** sur "Charger un module temporaire"
4. **Sélectionnez** le fichier `manifest.json` de l'extension
5. **L'extension se charge** temporairement

---

**📸 Espace réservé pour capture d'écran :** *Page about:debugging avec option de chargement temporaire*

---

### Gestion des Permissions

#### Vérifier les Permissions

1. **Allez dans** `about:addons`
2. **Trouvez** College Help AI
3. **Cliquez** sur les "..." → "Permissions"
4. **Consultez** toutes les permissions accordées

---

**📸 Espace réservé pour capture d'écran :** *Page des permissions de l'extension*

---

#### Ajuster les Permissions (Optionnel)

Firefox permet un contrôle granulaire :

- **Sites spécifiques** : Limitez l'accès à certains sites
- **Mode privé** : Autorisez ou interdisez en navigation privée
- **Données locales** : Contrôlez le stockage local

### 🔧 Dépannage Firefox

**L'extension ne se charge pas ?**
- Vérifiez que Firefox est à jour (version 78+)
- Redémarrez Firefox complètement
- Vérifiez que l'extension n'est pas désactivée dans `about:addons`

**Problèmes de permissions ?**
- Firefox peut demander confirmation pour certaines actions
- Vérifiez les paramètres de sécurité dans les préférences

**Extension temporaire disparue ?**
- Les extensions temporaires se déchargent au redémarrage
- Utilisez l'installation normale pour une utilisation permanente

**Conflits avec d'autres extensions ?**
- Désactivez temporairement les autres extensions pour tester
- Certaines extensions de sécurité peuvent bloquer College Help AI

**Autres problèmes ?**
- Consultez notre [guide de dépannage](../depannage/installation.md)
- Contactez notre [support](../ressources/contact.md)

### 💡 Conseils Firefox

- **Firefox Sync** : Synchronisez vos extensions sur tous vos appareils Firefox
- **Conteneurs** : College Help AI fonctionne dans tous les conteneurs Firefox
- **Mode strict** : Peut nécessiter des autorisations supplémentaires
- **Navigation privée** : Activez manuellement l'extension pour le mode privé
- **Performance** : Firefox optimise automatiquement l'utilisation mémoire des extensions

# 🔵 Installation sur Microsoft Edge

## Guide d'Installation Étape par Étape

### Méthode 1 : Installation depuis Microsoft Edge Add-ons (Recommandée)

#### Étape 1 : Ouvrir Microsoft Edge Add-ons

1. **Ouvrez Microsoft Edge** sur votre ordinateur
2. **Naviguez vers** le Microsoft Edge Add-ons : `edge://extensions/` ou [microsoftedge.microsoft.com/addons](https://microsoftedge.microsoft.com/addons)

---

**📸 Espace réservé pour capture d'écran :** *Page d'accueil de Microsoft Edge Add-ons*

---

#### Étape 2 : Rechercher College Help AI

1. **Cliquez sur la barre de recherche** en haut de la page
2. **Tapez** "College Help AI" ou "AI College Help"
3. **Appuyez sur Entrée** ou cliquez sur l'icône de recherche

---

**📸 Espace réservé pour capture d'écran :** *Résultats de recherche pour College Help AI*

---

#### Étape 3 : Installer l'Extension

1. **Localisez** "AI College Help - for homework and study" dans les résultats
2. **Cliquez sur l'extension** pour ouvrir sa page
3. **Vérifiez** que c'est la bonne extension (développeur officiel, bonnes évaluations)
4. **Cliquez sur "Obtenir"** ou "Ajouter à Edge"

---

**📸 Espace réservé pour capture d'écran :** *Page de l'extension avec bouton "Obtenir"*

---

#### Étape 4 : Confirmer l'Installation

1. **Une popup apparaît** avec la liste des permissions
2. **Lisez attentivement** les permissions demandées :
   - Lire et modifier les données des sites web
   - Accéder aux onglets et à l'activité de navigation
   - Stocker des données localement
3. **Cliquez sur "Ajouter l'extension"** pour confirmer

---

**📸 Espace réservé pour capture d'écran :** *Popup de confirmation des permissions*

---

#### Étape 5 : Vérification de l'Installation

1. **L'icône College Help AI** apparaît dans la barre d'outils Edge
2. **Un message de confirmation** s'affiche
3. **L'extension est prête** à être utilisée

---

**📸 Espace réservé pour capture d'écran :** *Icône de l'extension dans la barre d'outils Edge*

---

### Méthode 2 : Installation depuis Chrome Web Store

Microsoft Edge étant basé sur Chromium, il peut utiliser les extensions Chrome :

#### Étape 1 : Activer les Extensions Chrome

1. **Ouvrez Edge** et tapez `edge://extensions/` dans la barre d'adresse
2. **Activez** "Autoriser les extensions d'autres magasins"
3. **Cliquez sur "Autoriser"** dans la popup de confirmation

---

**📸 Espace réservé pour capture d'écran :** *Option "Autoriser les extensions d'autres magasins"*

---

#### Étape 2 : Installer depuis Chrome Web Store

1. **Visitez** le [Chrome Web Store](https://chrome.google.com/webstore)
2. **Recherchez** "College Help AI"
3. **Suivez** les mêmes étapes que pour Chrome
4. **Edge installera** automatiquement l'extension

---

**📸 Espace réservé pour capture d'écran :** *Installation depuis Chrome Web Store dans Edge*

---

### Configuration Post-Installation

#### Épingler l'Extension

Pour un accès facile, épinglez l'extension :

1. **Cliquez sur l'icône puzzle** 🧩 ou "Extensions" dans la barre d'outils
2. **Trouvez "College Help AI"** dans la liste
3. **Cliquez sur l'œil** 👁️ pour l'afficher dans la barre d'outils

---

**📸 Espace réservé pour capture d'écran :** *Menu des extensions avec option d'affichage*

---

#### Configurer les Raccourcis (Optionnel)

1. **Allez dans** `edge://extensions/shortcuts`
2. **Trouvez "College Help AI"**
3. **Configurez vos raccourcis préférés** :
   - Demander à College Help : `Ctrl+Shift+A`
   - Prendre une capture : `Ctrl+Shift+S`

---

**📸 Espace réservé pour capture d'écran :** *Page de configuration des raccourcis Edge*

---

### Méthode 3 : Installation Manuelle (Développeurs)

#### Si vous avez le fichier source :

1. **Ouvrez Edge** et tapez `edge://extensions/` dans la barre d'adresse
2. **Activez le "Mode développeur"** (bouton en bas à gauche)
3. **Cliquez sur "Charger décompressé"**
4. **Sélectionnez** le dossier contenant l'extension
5. **L'extension se charge** automatiquement

---

**📸 Espace réservé pour capture d'écran :** *Page edge://extensions avec mode développeur activé*

### 🔧 Dépannage Edge

**L'extension n'apparaît pas ?**
- Vérifiez que Edge est à jour (version 88+)
- Redémarrez Edge complètement
- Vérifiez dans `edge://extensions/` que l'extension est activée

**Problème avec les extensions Chrome ?**
- Assurez-vous d'avoir autorisé les extensions d'autres magasins
- Certaines fonctionnalités peuvent différer légèrement

**Extensions non synchronisées ?**
- Edge synchronise les extensions avec votre compte Microsoft
- Vérifiez vos paramètres de synchronisation

**Autres problèmes ?**
- Consultez notre [guide de dépannage](../depannage/installation.md)
- Contactez notre [support](../ressources/contact.md)

### 💡 Conseils Edge

- **Synchronisation Microsoft** : Vos extensions se synchronisent avec votre compte Microsoft
- **Performance** : Edge optimise automatiquement les performances des extensions
- **Compatibilité** : La plupart des extensions Chrome fonctionnent parfaitement sur Edge
- **Collections** : Vous pouvez organiser vos extensions dans des collections Edge

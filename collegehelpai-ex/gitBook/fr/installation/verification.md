# ✅ Vérification de l'Installation

## Comment Vérifier que College Help AI Fonctionne Correctement

### 🔍 Tests de Base

#### Test 1 : Vérification de l'Icône

1. **Regardez la barre d'outils** de votre navigateur
2. **Localisez l'icône College Help AI** 🎓
3. **L'icône doit être** :
   - ✅ Visible et colorée (pas grisée)
   - ✅ Cliquable
   - ✅ Affichant une info-bulle au survol

---

**📸 Espace réservé pour capture d'écran :** *Icône College Help AI dans la barre d'outils*

---

#### Test 2 : Ouverture du Popup

1. **Cliquez** sur l'icône College Help AI
2. **Le popup doit s'ouvrir** et afficher :
   - ✅ Le logo de l'extension
   - ✅ Les boutons "Connexion" et "S'inscrire" (si non connecté)
   - ✅ L'interface utilisateur (si connecté)
   - ✅ La version de l'extension en bas

---

**📸 Espace réservé pour capture d'écran :** *Popup principal de College Help AI*

---

#### Test 3 : Menu Contextuel

1. **Allez sur une page web** avec du texte
2. **Sélectionnez un mot ou une phrase**
3. **Clic droit** pour ouvrir le menu contextuel
4. **Vérifiez** la présence de l'option "Demander à College Help"

---

**📸 Espace réservé pour capture d'écran :** *Menu contextuel avec option College Help AI*

---

### ⌨️ Tests des Raccourcis Clavier

#### Test des Raccourcis par Défaut

| Raccourci | Action | Test |
|-----------|--------|------|
| `Ctrl+Shift+A` | Demander à College Help | Sélectionnez du texte puis testez |
| `Ctrl+Shift+S` | Prendre une capture | Testez sur n'importe quelle page |

##### Test du Raccourci d'Analyse de Texte :

1. **Sélectionnez** du texte sur une page web
2. **Appuyez** sur `Ctrl+Shift+A`
3. **Vérifiez** qu'une action se déclenche (popup ou analyse)

##### Test du Raccourci de Capture :

1. **Allez** sur n'importe quelle page web
2. **Appuyez** sur `Ctrl+Shift+S`
3. **Vérifiez** que l'outil de capture apparaît

---

**📸 Espace réservé pour capture d'écran :** *Outil de capture d'écran actif*

---

### 🔌 Vérification des Permissions

#### Vérification dans Chrome

1. **Allez dans** `chrome://extensions/`
2. **Trouvez** College Help AI
3. **Cliquez** sur "Détails"
4. **Vérifiez** que toutes les permissions sont accordées :

| Permission | Status | Description |
|------------|---------|------------|
| Lire et modifier les données | ✅ Accordée | Pour analyser le contenu des pages |
| Gérer les téléchargements | ✅ Accordée | Pour les captures d'écran |
| Stocker des données | ✅ Accordée | Pour sauvegarder les préférences |

---

**📸 Espace réservé pour capture d'écran :** *Page des permissions dans Chrome*

### 🌐 Test de Connectivité

#### Test de Connexion au Service

1. **Ouvrez** le popup College Help AI
2. **Si vous avez un compte**, connectez-vous
3. **Testez** une fonctionnalité qui nécessite Internet :
   - Analyse de texte
   - Capture d'écran avec analyse

#### Vérification du Statut de Connexion

Le popup doit afficher :
- ✅ **Connecté** : Nom d'utilisateur et plan visible
- ✅ **Hors ligne** : Message "Connexion Internet requise"
- ✅ **Non connecté** : Boutons de connexion/inscription

---

**📸 Espace réservé pour capture d'écran :** *Différents états de connexion*

---

### 🧪 Tests Fonctionnels Complets

#### Test d'Analyse de Texte

1. **Allez** sur une page avec du texte éducatif
2. **Sélectionnez** une phrase ou un paragraphe
3. **Utilisez** le raccourci `Ctrl+Shift+A` ou le menu contextuel
4. **Vérifiez** que :
   - ✅ L'analyse démarre
   - ✅ Une réponse est générée
   - ✅ La réponse s'affiche correctement

#### Test de Capture d'Écran

1. **Allez** sur une page avec du contenu visuel (équation, graphique)
2. **Appuyez** sur `Ctrl+Shift+S`
3. **Sélectionnez** une zone en glissant la souris
4. **Vérifiez** que :
   - ✅ La capture est prise
   - ✅ L'analyse démarre
   - ✅ Une réponse pertinente est fournie

---

**📸 Espace réservé pour capture d'écran :** *Processus complet de capture et analyse*

### 📊 Diagnostic Avancé

#### Vérification des Logs de Console

Si vous rencontrez des problèmes :

1. **Ouvrez** les outils développeur (`F12`)
2. **Allez** dans l'onglet "Console"
3. **Recherchez** des messages d'erreur liés à College Help AI
4. **Prenez note** des erreurs pour le support technique

#### Test de Performance

L'extension doit :
- ✅ Se charger en moins de 2 secondes
- ✅ Répondre aux clics instantanément  
- ✅ Analyser le texte en moins de 5 secondes
- ✅ Ne pas ralentir la navigation

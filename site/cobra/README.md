## 🌟 Aperçu

Cobra est un thème WordPress premium développé pour les sites d'extensions éducatives. Il combine design moderne, performance optimisée et fonctionnalités SEO avancées.

### ✨ Fonctionnalités principales

- 🚀 **Performance optimisée** - Temps de chargement ultra-rapide
- 📱 **Design responsive** - Parfait sur tous les appareils
- 🔍 **SEO avancé** - Schema.org, Open Graph, Twitter Cards
- ♿ **Accessibilité WCAG 2.1 AA** - Inclusif pour tous
- 🎨 **Animations modernes** - Interface interactive et engageante
- 🔒 **Sécurisé** - Headers de sécurité et bonnes pratiques
- 🌙 **Mode sombre** - Support automatique du thème système

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Backend**: PHP 7.4+, WordPress 5.0+
- **Frameworks**: Bootstrap 5.1.3
- **Icons**: Font Awesome 6.4.0
- **Analytics**: Microsoft Clarity
- **Performance**: Lazy loading, Critical CSS, Preconnect

## 🚀 Installation rapide

### Méthode 1: Déploiement automatique (Recommandé)
```powershell
# Cloner le repository
git clone https://github.com/nakous/cobra_theme.git

# Naviguer vers le dossier
cd cobra_theme

# Exécuter le script de déploiement
.\deploy-to-xampp.ps1
```

### Méthode 2: Installation manuelle
1. Téléchargez ou clonez ce repository
2. Copiez le dossier vers `/wp-content/themes/`
3. Activez le thème dans WordPress Admin
4. Configurez les options dans **Apparence > Personnaliser**

## 📋 Prérequis

- **WordPress**: 5.0 ou supérieur
- **PHP**: 7.4 ou supérieur
- **MySQL**: 5.6 ou supérieur
- **Apache/Nginx**: Avec mod_rewrite activé

## 🚀 Scripts de déploiement

Le thème inclut plusieurs scripts de déploiement :

### `deploy-to-xampp.ps1` (Recommandé)
Script PowerShell complet avec interface utilisateur
```powershell
.\deploy-to-xampp.ps1
```

### `deploy-advanced.ps1`
Script avancé avec configuration automatique
```powershell
.\deploy-advanced.ps1 -Force -AutoConfig
```

### `deploy-to-xampp.bat`
Script Batch simple et rapide
```cmd
deploy-to-xampp.bat
```
